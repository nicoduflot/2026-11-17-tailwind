Installation et bases

Installation

Il est possible d'installer tailwind sur différents frameworks. Dans ce projet, nous allons l'installer sur un projet sans framework, en utilisant Tailwint CLI

  1. Il faut utiliser un terminal et se rendre à la racine du projet.
  2. Une fois à cet endroit, il faut utiliser npm pour laner la commande suivante :
    npm install tailwindcss @tailwindcss/cli
  3. Dans le projet, prévoir un fichier css d'entrée, par exemple à cet endroit :
    ./src/tailwind/intput.css, sur lequel on inscrit la ligne suivante :

@import "tailwindcss";

  1. A nouveau dans le terminal, on va lui demander de "surveiller" le fichier input, et d'écrire le css compilé par tailwind sur un autre fichier css, ici il sera dans
    ./src/css/style.css, en utilisant la commande suivante :
    npx @tailwindcss/cli -i ./src/tailwind/input.css -o ./src/css/style.css --watch

Support Visual Studio Code

Pour VS Code, il est recommandé d'utiliser le pluggin *Tailwind CSS intelliSense, qui ajoutera :

  • Autocomplétion
  • Affichage des erreurs d'utilisation
  • affichage du css créé au survol
  • coloration syntaxique

Il est aussi recommendé d'utiliser le pluggin Prettier, il va trier les classes dans les éléments dans l'ordre recommandé par le framework.

Les IDE de la suite Jetbrains et Zed supportent aussi tailwind.

Les classes utilitaires

Quand on a compilé une première fois le CSS tailwind, il nous génère un fichier contenant un reset css drastique :

  • tous les éléments appliquent la même taille de police
  • tous les éléments appliquent le même poids de police
  • etc.

Fonctionnement de tailwind (en mode cli)

Le terminal scan les fichiers et si un fichier est lié au CSS de sortie, ici style.css, dès qu'une classe de tailwind est ajoutée a ce fichier, il compile le CSS nécessaire et l'ajoute au fichier de sortie CSS.
