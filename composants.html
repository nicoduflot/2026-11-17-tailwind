Créer des composants

Un composant (ou module) consiste à créer des fichier css séparés pour créer des éléments réutilisables afin de créer une bibliothèque.

Cela évite principalement d'avoir à copier / coller une suite de classes Tailwind pour que tous les éléments semblable d'une page aient le même style.

Il faut créer tout d'abord un fichier d'input pour Tailwind, dans lequel on va au choix prendre tout le CSS de base de tailwind ou comme dans l'exemple suivant une partie des éléments. 


// Structure des fichiers dans ce projet
src/
 ├── css/
 |    └── cs-style.css          // Fichier de sortie généré par Tailwind
 |
 └── tailwind/                  // répertoire des fichiers a compiler pour la sortie
       ├── components/          // répertoire des composants réutilisables
       |    ├── buttons.css     
       |    ├── navigation.css 
       |    └── typography.css
       └── cs-input.css         // fichier principal de création du fichier de sortie
//

Une fois tous les fichiers créés, il faut écrire les composants en CSS en utilisant @layer, qui permet de créer des classes réutilisables.

En CSS, @layer (les calques de cascade) sert à contrôler l'ordre de priorité de vos règles CSS sans avoir à utiliser !important ni à vous soucier de la complexité des sélecteurs.

Imaginez-le comme une pile de feuilles transparentes : la feuille posée tout en haut l'emporte toujours sur celles du dessous, peu importe la longueur ou la précision du sélecteur écrit dessus.

Comme il faut essayer de réutiliser l'écosystème de Tailwind, on peut implémenter dans ces classes maison les classe déjà prêtes de Tailwind grace à @apply

@apply est une directive de Tailwind qui permet de regrouper plusieurs classes utilitaires (comme flex, bg-blue-500, p-4) à l'intérieur d'une classe CSS classique.

C'est un raccourci pour éviter de répéter la même longue liste de classes utilitaires dans votre HTML. 


// buttons.css
@layer components {
    .btn-primary{
        @apply 
            px-4 py-2 rounded font-bold 
            bg-blue-600 text-white 
            transition duration-200
            hover:bg-blue-700
            ;
    }

    /*

Intégrer les composants

Pour Intégrer les composants, il est possible de créer le fichier d'entrée avec seulement quelques éléments de Tailwind plutôt que toute la structure.

Au lieu d'utiliser @import "tailwindcss"; on utilisera : 


// fichier cs-input.css
@import "tailwindcss/theme.css"; /* les "fonctions" qui permettent de générer les éléments particulier de Tailwind */
@import "tailwindcss/preflight"; /* @tailwind base; */
@import "tailwindcss/utilities.css";

// intégration des fichiers de composants 
@import "./components/buttons.css";
@import "./components/navigation.css";
@import "./components/typography.css";
  1. tailwindcss/theme.css : Le socle des "Design Tokens" (Variables CSS)
    Ce fichier contient toutes les variables CSS par défaut de Tailwind (les couleurs comme --color-blue-600, les espacements, les tailles de police, les ombres, les points de rupture pour le responsive, etc.).
  2. tailwindcss/prefligh : Le reset CSS de base (anciennement @tailwind base;)
  3. tailwindcss/utilities.css : Le générateur de toutes les classes utilitaires (p-4, flex, etc.)
